## 怎样使用

算法零基础先按复习路线阅读，跟着例题手算，再独立完成章末练习，最后核对答案并做综合训练。自动控制理论可以在线读 Markdown，或下载排版 PDF 手算、打印。软件工程先看流程总表，再跟随“作业记录器”例子串联各阶段。

讲义中区分教学自编题、教材题和课件原例；页码与题号沿用整理时提供的教材及课件版本。引用原材料的地方保留名称和页码，请结合自己的原文件使用。本仓库未收录教材、原始课件、笔记扫描件和核对截图。

实验报告、实验配套程序、生成脚本、工具依赖和临时文件暂不上传。原始本地资料保留，仓库副本中的章节链接已改为相对链接。
