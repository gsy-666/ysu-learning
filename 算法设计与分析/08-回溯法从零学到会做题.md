# 第08讲：回溯法，从零学到会做题

依据：你确认回溯法也在考试范围；绪论课件目录列出一般方法、八皇后、子集和数。本文件夹暂未提供回溯课件，本讲参考教材第8章，重点是书页193起的一般方法、202起的皇后、204起的子集和数。下面用自编小例先建立理解。

## 1. 从“一个选择不行，再换一个”理解回溯

有些题无法只靠一次贪心选择就确定答案，需要尝试不同方案。例如四皇后，第一行放哪一列会影响后面几行；如果放到第三行时无路可走，就回到上一行换位置。

回溯的基本过程是：记录当前选择，继续向下；发现不可能成功就停止这条分支，撤销当前选择，回到上一步试别的。递归适合表达这种过程，因为每一层负责一项选择。

递归是调用方式，回溯是探索候选方案的策略。只看到函数调用自己，不能立刻说它就是回溯。

## 2. 解空间树、约束与剪枝

假设有3件物品，每件可选或不选。用x=(x₁,x₂,x₃)表示方案，xᵢ=1为选，0为不选。第一层决定x₁，第二层决定x₂，第三层决定x₃，完整方案共有2³=8个。

```text
根：还没决定任何物品
├─ x₁=1
│  ├─ x₂=1 → 再试x₃=1或0
│  └─ x₂=0 → 再试x₃=1或0
└─ x₁=0
   ├─ x₂=1 → 再试x₃=1或0
   └─ x₂=0 → 再试x₃=1或0
```

树中的结点记录已经作出的选择，根表示空的部分解，根到叶的一条路径表示一个完整候选。这里左右分支的含义已经明确，画树时不要中途交换。

| 术语 | 直观含义 |
|---|---|
| 显式约束 | 每个分量可取什么值，例如xᵢ只能是0或1 |
| 隐式约束 | 不同选择之间还必须满足的关系，例如重量和恰好为M |
| 部分解 | 只决定了前几项，还未完成全部任务 |
| 扩展 | 在部分解后增加一项选择 |
| 剪枝 | 已确定该部分解不可能产生所要求的答案，不再往下试 |
| 回溯 | 当前分支结束，返回上层，恢复现场并尝试其他分支 |

剪枝必须有理由。只因为“这个选择看起来不太好”就删掉它，可能漏解。找一个解、找全部解、找最优解，停止条件也不同。

## 3. 通用代码骨架与“撤销”

下面是拟SPARKS骨架，其中中文操作要根据具体问题替换：

```text
procedure SEARCH(k)
    if 已经得到完整合法方案 then
        输出或保存方案
        return
    endif
    for 每个当前层候选c do
        if 加入c后仍有可能得到答案 then
            记录本次选择
            call SEARCH(k+1)
            撤销本次修改
        endif
    repeat
end SEARCH
```

本层调用下一层后，不会永远消失；下一层返回，执行位置就在递归调用后面。因此撤销写在调用后，保证下一次候选是在干净的状态上尝试。

若用局部参数s+w传递当前和，各次调用自带自己的s，返回时外层s没有被改；若用共享数组used标记占用，就必须手动恢复。要根据变量怎样保存来判断需不需要撤销。

## 4. 皇后问题：先把棋盘规则变成数字

在n×n棋盘上放n个皇后，要求任意两个不能在同一行、同一列、同一条对角线上。八皇后对应n=8，入门先用n=4。

规定第k层只给第k行放一个皇后，用x(k)记录该行的列号。这样每行恰有一个皇后，同行冲突已经由表示方式排除。还需检查同列和对角线。

对前面第j行和当前第k行，j<k：

```text
同列冲突：x(j)=x(k)
对角线冲突：ABS(x(j)−x(k))=k−j
```

对角线每向下走1行，列也向左或右变化1。因此列差的绝对值等于行差时就在同一条对角线上。

例如第1行第2列与第3行第4列，行差2、列差2，发生对角线冲突；与第3行第1列，行差2、列差1，没有这两种冲突。

### 4.1 四皇后的一个完整方案

x=(2,4,1,3)表示：

```text
第1行：· Q · ·
第2行：· · · Q
第3行：Q · · ·
第4行：· · Q ·
```

各列不同；任意两行的列差也不等于行差，所以是合法方案。四皇后另一个方案为(3,1,4,2)。这里统计全部位置方案，不做旋转、镜像去重。

### 4.2 按列从小到大尝试，怎样走到答案

| 当前状态 | 尝试与结果 |
|---|---|
| 空 | 第1行先放第1列，得到(1) |
| (1) | 第2行第1列同列，第2列斜线；第3列可行，得(1,3) |
| (1,3) | 第3行四列都冲突，返回并撤销第2行第3列 |
| (1) | 第2行改试第4列，得(1,4) |
| (1,4) | 第3行可放第2列，得(1,4,2) |
| (1,4,2) | 第4行无合法列，退回；这一大分支最终失败 |
| 空 | 第1行改放第2列，得(2) |
| (2) | 第2行第4列可行，得(2,4) |
| (2,4) | 第3行第1列可行，得(2,4,1) |
| (2,4,1) | 第4行第3列可行，输出(2,4,1,3) |

输出后若找全部解，仍继续返回尝试其余候选；若只找第一个，必须把“已经找到”的信号向上层传递，而不是只退出最内层for。

### 4.3 完整SPARKS实现

使用全程数组x保存列号，used(col)表示该列是否占用。used负责排除同列；SAFE检查与先前皇后的对角线。下面三个过程组成同一算法，n≥1。

```text
procedure SOLVE_QUEENS(n)
    global integer size,count,x(1:n)
    global boolean used(1:n)
    size ← n; count ← 0
    for i ← 1 to size do
        x(i) ← 0
        used(i) ← false
    repeat
    call PLACE_ROW(1)
    return(count)
end SOLVE_QUEENS

procedure SAFE(k,col)
    global x
    for j ← 1 to k-1 do
        if ABS(x(j)-col) = k-j then
            return(false)
        endif
    repeat
    return(true)
end SAFE

procedure PLACE_ROW(k)
    global size,count,x,used
    if k > size then
        print(x)
        count ← count+1
        return
    endif
    for col ← 1 to size do
        if (not used(col)) and SAFE(k,col) then
            x(k) ← col
            used(col) ← true
            call PLACE_ROW(k+1)
            used(col) ← false
            x(k) ← 0
        endif
    repeat
end PLACE_ROW
```

size与输入n用不同名字，因为SPARKS标识符不区分大小写，不能用n与N代表两个变量。各调用的k、col、j属于其本次调用的参数或局部变量；共享的只有明确列出的全程状态。

重点读连续四步：写x(k)→标记used→递归→恢复used和x(k)。删掉恢复used会让后面分支误以为某列一直被占用，造成漏解。

### 4.4 复杂度怎样说明

同列已被排除时，完整候选至多是n列的排列，共n!个；剪掉对角线冲突后实际通常少很多。短路and使SAFE只在未占用列上调用，这些候选扩展的总数为O(n!)，每次SAFE最坏检查O(n)个先前皇后；扫描列候选的成本也在同一上界内。因此一个保守时间上界可写O(n·n!)，不要称为紧确实际次数。若采用不同候选生成和检查方法，界也可能不同。

x、used为O(n)，最大递归深度O(n)，辅助空间合计O(n)，不是O(n!)。书中PLACE逐次扫描先前皇后时为O(k−1)，要把检查成本与搜索规模分开。

## 5. 子集和数：每件物品选或不选

给定正整数重量w(1:n)和目标M，要求找出所有重量和恰好为M的子集。用choose(i)=1表示选第i件，0表示不选；每件最多选一次。

自编例子：重量[2,3,5]、目标5。答案为{2,3}和{5}，对应(1,1,0)和(0,0,1)。要求恰好等于5，不能把总重4或6算进去。

### 5.1 状态必须说清

定义SUBSET_SEARCH(i,s,r)：准备决定第i件；前i−1件的选择已确定；已选重量和为s；未决定物品i至n的重量总和为r。

- 选第i件：下一状态为(i+1,s+w(i),r−w(i))。
- 不选第i件：下一状态为(i+1,s,r−w(i))。

无论选不选，第i件都会被决定，所以r都要减w(i)。只有选它时s才增加。

### 5.2 两个剪枝条件为什么安全

若s>M，剩余重量都是正数，再加只会更大，无法回到M。若s+r<M，即使把剩余全部选上也不够，同样无法成功。

这两个理由依赖所有重量为正。如果允许负数，超出目标之后可能再加负数回到目标，不能照搬剪枝。

教材SUMOFSUB还有利用非递减排序加强的检查。本讲用上面两个较直观条件，不假装是逐字照抄教材版本；做教材指定算法过程题时按原排序与左右分支约定。

### 5.3 完整算法

下面的包装过程复制输入，设置全程状态；枚举过程使用参数保存各层的s、r。

```text
procedure ENUM_SUBSETS(A,n,goal)
    //A为正整数数组，n≥0，goal≥0，输出所有恰好等于goal的子集//
    global integer size,target,weights(1:n),choose(1:n)
    size ← n; target ← goal; remaining ← 0
    for i ← 1 to size do
        weights(i) ← A(i)
        choose(i) ← 0
        remaining ← remaining+weights(i)
    repeat
    call SUBSET_SEARCH(1,0,remaining)
end ENUM_SUBSETS

procedure SUBSET_SEARCH(i,s,r)
    global size,target,weights,choose
    if s = target then
        for j ← i to size do
            choose(j) ← 0
        repeat
        print(choose)
        return
    endif
    if i > size then return endif
    if (s > target) or (s+r < target) then return endif

    choose(i) ← 1
    call SUBSET_SEARCH(i+1,s+weights(i),r-weights(i))
    choose(i) ← 0
    call SUBSET_SEARCH(i+1,s,r-weights(i))
end SUBSET_SEARCH
```

空输入时不访问数组；goal=0时空子集是合法方案。若在纸面声明中不允许空范围，可以把n=0作为包装过程的特殊情况另行写出。

成功时将尚未决定的后缀置0再输出，因为正重量下当前和已经等于目标，后面只能全部不选。choose(i)←0既撤销选中标记，也为不选分支设置了状态。

### 5.4 完整小例的分支结果

按先选后不选，重量[2,3,5]、目标5：

| 已经决定的选择 | 当前和s | 处理 |
|---|---:|---|
| 选2、选3 | 5 | 输出(1,1,0)，后面5不选 |
| 选2、不选3、选5 | 7 | 超重，剪枝 |
| 选2、不选3、不选5 | 2 | 已无物品，失败 |
| 不选2、选3、选5 | 8 | 超重，剪枝 |
| 不选2、选3、不选5 | 3 | 已无物品，失败 |
| 不选2、不选3、选5 | 5 | 输出(0,0,1) |
| 不选2、不选3、不选5 | 0 | 已无物品，失败 |

表格列出主要路径；代码也可能提前通过s+r不足进行剪枝，不必走到某些叶子。画树时，应把真正生成的结点和已经剪去的子树区分开。

### 5.5 时间与空间

n件物品有2ⁿ种选取。若每个搜索结点只做常数状态更新，不计输出整份向量，最坏时间O(2ⁿ)。每输出一份长度n的向量另需O(n)，所以更完整可写O(2ⁿ+nK)，K为输出方案数。

存数组和最长调用链都为O(n)，不把所有方案保存在内存时辅助空间O(n)。如果将K个完整答案全部存下，还要加O(nK)结果存储。

## 6. 找一个解与全部解怎样区别

全部解版本在输出后返回上一层，继续试其他候选。只求一个解，可以把递归过程改成返回布尔值：某分支成功则返回true，逐层向上；所有候选都失败才返回false。

仅在最内层用exit不够，因为exit只离开当前最内层循环，外层仍可能继续。全程found标记也可实现提前停止，但每一层都要检查并传播退出意图。

## 7. 算法题与过程题的答题方式

算法题依次说明：解向量含义；第k层决定什么；可选值；合法性或界限判断；何时得到答案；怎样恢复状态；最坏搜索规模与空间。

过程题先写明左右分支含义或皇后候选顺序；每个结点标当前层、部分解或当前和；在剪枝位置写明“冲突”“超重”“即使全选仍不足”等理由。不能只写最终答案而没有题目要求的树或过程。

## 9. 标准答案与详细解析

### 第1题：行与解向量

**答案：每层只给一行放一个皇后，已经保证同行不会重复；x(3)=4表示第3行第4列有皇后。**

第k层对应第k行，层号不同，行就不同。因此只需继续检查列与对角线。x的下标是行号，数组里存放的值是列号，两者不可颠倒。

### 第2题：两次位置尝试

**答案：第3行第4列与已有皇后冲突；第3行第1列不与该皇后冲突。**

已有皇后在(1,2)。对(3,4)，行差|3−1|=2、列差|4−2|=2，在同一条对角线上；对(3,1)，行差2、列差1，且不同列，不与(1,2)冲突。若前面还有其他皇后，仍需分别检查后才能决定整体是否合法。

### 第3题：完整检查四皇后方案

**答案：(2,4,1,3)是合法四皇后方案。**

列号2、4、1、3互不重复；同行已由表示方式排除；六对行的对角线检查如下：

| 两行 | 行差 | 列差绝对值 | 冲突吗 |
|---|---:|---:|---|
| 1、2 | 1 | 2 | 否 |
| 1、3 | 2 | 1 | 否 |
| 1、4 | 3 | 1 | 否 |
| 2、3 | 1 | 3 | 否 |
| 2、4 | 2 | 1 | 否 |
| 3、4 | 1 | 2 | 否 |

每对都不满足列差等于行差，所以无对角线冲突。只检查相邻行并不足够。

### 第4题：忘记撤销used

**答案：会让已经撤销的皇后继续占用列标记，导致后续分支被错误排除，漏解。**

例如本分支试过某列后返回，如果used仍为true，换另一个部分解时就会误判该列已有人。递归调用结束要恢复的是共享状态；本地参数会随返回恢复，但共享数组不会自动撤销。

### 第5题：目标6的全部子集

**答案：恰好两组，{2,4}与{6}，按原编号的向量为(1,1,0)与(0,0,1)。**

全部子集和按选取情况列为：空集0，单件2、4、6，两件6、8、10，三件12。等于6的正是选前两件或只选第三件；相同的总和对应不同物品组合，均应保留。

### 第6题：剪枝及其前提

**答案：s=6、M=9、r=2时可以剪枝；若允许后续负数，s>M不能直接推出失败。**

因为s+r=8<9，剩余全选也不够。超重剪枝使用正重量前提：继续选只能变重；若允许负数，已选和12还能加−3回到9，所以这条剪枝不再安全。

### 第7题A：教材8.8的全部答案

**答案：共4个子集，分别为{5,10,20}、{5,12,18}、{7,10,18}、{15,20}。**

原题在教材书页215／PDF第222页。按照原数组W=(5,7,10,12,15,18,20)的顺序，完整0/1向量为：

| 选中重量 | 向量X | 核验 |
|---|---|---|
| 5、10、20 | (1,0,1,0,0,0,1) | 5+10+20=35 |
| 5、12、18 | (1,0,0,1,0,1,0) | 5+12+18=35 |
| 7、10、18 | (0,1,1,0,0,1,0) | 7+10+18=35 |
| 15、20 | (0,0,0,0,1,0,1) | 15+20=35 |

教材在命中目标时可只打印X(1:k)，尚未决定的后缀全不选、补0后，就是表中完整的7维向量。

下面使用教材算法8.6，而不是本讲第5节较通用的剪枝版本。结点标(s,k,r)：s为前k−1件已选总重，k为本次考察物品，r为从k到n尚未决定的全部重量。初始r=87，调用SUMOFSUB(0,1,87)。左分支X(k)=1，右分支X(k)=0。

教材利用正重量已非递减排序，递归条件是：选当前后若已达35则输出；若未达到且s+W(k)+W(k+1)≤35，才深入选分支。不选分支须同时满足s+r−W(k)≥35与s+W(k+1)≤35。后两项分别确保剩余总重够、下一件最小重量仍装得下。

```text
  │ │     └─x6=1 → ✓ {7,10,18}
  │ └─x3=0 → (7,4,65)

```

例如(22,4,65)表示已选5、7、10，正考虑12。选12后为34，下一件至少15，无法补成35；不选12后，下一件15与当前22已超35，所以两边都不再调用。

### 第7题B：教材8.10的可变长度元组算法

**答案：用已选物品编号构成元组，按严格递增编号扩展，达到目标时输出元组。完整代码如下。**

例如{5,10,20}用编号元组(1,3,7)表示，{15,20}用(5,7)表示。长度分别为3和2；固定0/1表示则两者都需要7项。物理存储可用长度n的path数组加当前长度k，输出时只取前k项。

```text
procedure SUM_TUPLES(A,n,goal)
    //A为正整数重量数组，n≥1，goal≥0；输出全部解的编号元组//
    global integer countItems,target,weights(1:n),path(1:n)
    countItems ← n; target ← goal
    for j ← 1 to n do
        weights(j) ← A(j)
        path(j) ← 0
    repeat
    call SEARCH_TUPLES(1,0,0)
end SUM_TUPLES

procedure SEARCH_TUPLES(start,s,k)
    //下一次只能选编号≥start的物品；已选和s，元组长度k//
    global countItems,target,weights,path
    if s = target then
        print(path(1:k))
        return
    endif
    for j ← start to countItems do
        if s+weights(j) ≤ target then
            path(k+1) ← j
            call SEARCH_TUPLES(j+1,s+weights(j),k+1)
            path(k+1) ← 0
        endif
    repeat
end SEARCH_TUPLES
```

print(path(1:k))表示输出元组当前前k项，k=0时输出空元组。start使用j+1，保证每件只选一次，也避免把(1,3,7)和(3,1,7)重复输出。for直接跳到后面的候选，已经隐含“不选中间那些物品”，因此无需另写一个0分支。

正确性：任何合法子集都能按下标递增唯一排列，算法会逐项枚举到它；正重量下，已选和超过目标不可能补救，因此只扩展不超重的候选不会漏解。返回后清除本次path项，再尝试下一候选。

最坏搜索为指数规模，不计输出时可用O(2ⁿ)上界；若输出K个最多长n的元组，加O(nK)输出成本。辅助数组与递归深度均为O(n)。本题不依赖排序；若排序，可再利用最小候选与剩余重量加强剪枝，但输出编号需明确对应关系。
