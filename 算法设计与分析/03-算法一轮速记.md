每个算法回忆四件事：解决什么问题；核心选择或状态是什么；执行过程怎样走；时间复杂度是多少。回忆不出来时，返回对应详细章节的完整例题；不再以两天内翻完作为强制目标。

## 1. 基础：回顾这些就往下走

- 五特性：确定性、能行性、输入、输出、有穷性。
- O是渐近上界，Ω是渐近下界，Θ是紧确界；它们与最好、最坏情况是不同维度。
- 常见增长阶：1、log n、n、n log n、n²、2ⁿ，依次增长更快。
- 顺序循环加次数；嵌套循环数各轮真实次数；每轮缩小一半通常是对数级。
- 辅助空间要计算额外数组、变量及递归调用栈。
- SPARKS：←赋值，=比较，A(i)访问数组；while为真时继续，until为真时结束；for默认步长+1；repeat按循环结构配对。
- exit离开最内层循环；return离开当前过程；函数值通过return(值)给出，纯过程也可用输出参数带出结果。
- 栈是后进先出，队列是先进先出；空满条件要按题中指针约定判断。

语法卡住再查 [SPARKS详解](02-SPARKS语言详解.md)。

## 2. 递归：出口、缩小规模、返回结果

递归是直接或间接调用自身。先写最小规模的答案，再把原问题交给更小规模的同类问题；每条递归路径都要能到达出口。

阶乘，输入为非负整数：

```text
procedure FACT(n)
    if n = 0 then return(1) endif
    return(n*FACT(n-1))
end FACT
```

FACT(3)先调用FACT(2)、FACT(1)、FACT(0)，再依次返回1、1、2、6。调用过程中尚未完成的乘法保存在调用栈里。

| 例子 | 核心递推 | 时间与空间 |
|---|---|---|
| 阶乘 | F(0)=1；F(n)=nF(n−1) | 按基本算术为常数时间，时间Θ(n)，栈Θ(n) |
| 汉诺塔 | T(0)=0；T(n)=2T(n−1)+1 | 移动2ⁿ−1次，时间Θ(2ⁿ)，栈Θ(n) |
| 朴素Fibonacci | F(0)=0，F(1)=1；F(n)=F(n−1)+F(n−2) | 大量重复计算，指数级；常用上界O(2ⁿ)，栈Θ(n) |

递归不必然低效。Fibonacci改成保存已算结果或循环递推，可以在线性时间内计算；循环版只保留相邻两项时辅助空间为Θ(1)。简单递推可改循环，一般递归转非递归可用显式栈保存执行状态。

## 3. 分治：分解、分别求解、合并

递归是调用方式，分治是解题策略。典型分治把原问题分成较小的子问题，分别解决，再组合答案。

| 算法 | 核心做法 | 应记复杂度或区别 |
|---|---|---|
| 二分检索 | 有序数组取中点，排除不含目标的一半 | 最好Θ(1)，最坏Θ(log n)；迭代辅助空间Θ(1) |
| 同时找最大最小 | 左右各求最大最小，再作两次合并比较 | 时间Θ(n)；n为2的幂时比较3n/2−2次 |
| 归并排序 | 分两半递归排好，再合并两个有序段 | 时间Θ(n log n)，常规数组实现辅助空间Θ(n) |
| 快速排序 | 用基准划分两侧，再分别排序 | 平均Θ(n log n)，最坏Θ(n²)；划分过程依具体版本 |
| 第k小元素 | 划分后只进入含目标排名的一侧 | 常见划分选择平均Θ(n)、最坏Θ(n²) |
| Strassen | 分块后用7次子矩阵乘法代替8次 | Θ(n^log₂7)，约Θ(n^2.807) |

归并的主要工作是合并；快排的主要工作是划分。常规归并可保持稳定；常规快排不稳定。快排过程题必须按指定基准和指针规则，不同正确版本的中间序列可以不同。

三个递推式一起记：T(n)=T(n/2)+Θ(1)为Θ(log n)；T(n)=2T(n/2)+Θ(n)为Θ(n log n)；T(n)=T(n−1)+Θ(n)为Θ(n²)。

第k小中的k可能是当前段内排名，也可能用全数组下标表示，要先看算法定义。Strassen的组合公式有一处课件符号问题，见 [勘误](课件勘误.md)。

## 4. 贪心：每步按规则选择，并证明这样选安全

相关概念：约束条件决定可行解，目标函数决定怎样比较好坏，最优解是可行解中目标最优的解。贪心通常需要贪心选择性质和最优子结构；成功算出几个例子不能代替正确性证明。

| 问题 | 每次怎样选 | 前提与复杂度 |
|---|---|---|
| 可分割背包 | 按价值/重量降序，放不下时取部分 | 物品可分割；计排序通常O(n log n)，排好后扫描O(n) |
| 最优归并 | 每次合并当前最小的两个文件 | 合并代价为大小之和；用最小堆O(n log n) |
| Prim | 选连接已选顶点集合与外部的最轻边 | 求无向连通图MST；矩阵版本O(V²) |
| Kruskal | 全图边按权排序，依次选不会成环的边 | 排序加并查集通常O(E log E) |
| Dijkstra | 选距源点暂定距离最小的未确定顶点，更新邻点 | 边权非负；矩阵版本O(V²) |

图的顶点是对象，边表示连接，权表示代价。生成树包含全部顶点、连通且无环，共V−1条边。MST使总边权最小，允许负权；Dijkstra使源点到各点的路径最短，要求非负权。

Dijkstra更新：dist[v] ← min(dist[v],dist[u]+w(u,v))。Prim比较的是接入树的那条边，Dijkstra比较的是从源点累计的距离。

0/1背包每件只能选或不选，不能直接照搬密度贪心。交换论证的常见思路：将某个最优解的选择换成贪心选择，证明仍可行且目标不变差，再递推到余下问题。

## 5. 动态规划：状态、边界、转移、顺序、方案

先用一句话说清状态，再写公式。最优子结构用于建立递推；保存子问题结果可以减少重复求解。自底向上填表时，被依赖的状态必须先算好；需要具体方案时还要记录选择。

| 问题 | 状态及核心转移 | 边界、顺序和复杂度 |
|---|---|---|
| 0/1背包 | K(i,c)为前i件、容量上限c的最大价值；放得下时max(K(i−1,c),K(i−1,c−wᵢ)+vᵢ)，放不下继承上一行 | 正重量下K(0,c)=K(i,0)=0；逐行算，O(nM)；一维优化时容量倒序 |
| 多段图 | C(u)为u到终点的最短距离；C(u)=min(w(u,v)+C(v)) | 终点为0，从后续阶段往前算；邻接表逐边处理O(V+E) |
| Floyd | d[i,j]表示当前允许的中间点范围下的最短距离；d[i,j]=min(d[i,j],d[i,k]+d[k,j]) | 初值为直接边权、无边∞、对角0；k必须在最外层；O(V³)时间、O(V²)空间；要求没有负环影响的有限最短路 |
| 矩阵连乘 | m[i,j]是Ai…Aj的最少标量乘法数；枚举i≤k<j，取m[i,k]+m[k+1,j]+pᵢ₋₁pₖpⱼ的最小值 | m[i,i]=0，按区间长度递增；O(n³)时间、O(n²)空间 |
| LCS | c[i,j]是两个前缀的最长公共子序列长度；末元素相同取左上+1，不同取上、左最大值 | 任一前缀为空则0；O(mn)时间，常规二维表O(mn)空间；子序列不必连续 |
| 货郎担TSP | g(i,S)为从i出发，走完未访问集合S再回起点的最小成本；min(cᵢⱼ+g(j,S\{j}))，j∈S | g(i,空集)=cᵢ₁；按集合大小算，时间O(n²2ⁿ)，空间O(n2ⁿ) |

矩阵连乘只改变括号，不改变矩阵顺序；Ai尺寸为pᵢ₋₁×pᵢ。TSP必须访问全部要求的顶点并回起点；它不是一般单源最短路径。

算法题可按固定顺序作答：定义状态→边界→转移→计算顺序→答案所在位置→方案恢复→复杂度。矩阵连乘分割点和LCS边界有课件笔误，按勘误使用。

## 6. 回溯：试探、检查、深入、撤销

解空间树表示全部候选选择；结点代表当前部分解。符合约束并完成全部选择时得到解；不可能得到要求的解时剪去分支。

通用过程：枚举当前层候选→判断是否可行→记录选择→递归进入下一层→撤销本次修改→继续试下一个候选。找到一个解即可停止与找出全部解，退出方式不同。

八皇后：每行放一个皇后，x[k]表示第k行所在列。新皇后与之前第j行的皇后不能同列，即x[k]≠x[j]；也不能同对角线，即|x[k]−x[j]|≠k−j。先用四皇后理解过程，再看八皇后。

子集和：每件物品选或不选，目标是所选重量之和等于M。若重量都为正，可用“当前和>M”或“当前和+剩余所有重量<M”排除分支；有负数时不能直接套这些剪枝。n件物品有2ⁿ种选取，最坏搜索规模为指数级。

回溯也常用递归实现，但“调用自身”只是实现方式；试探不同选择和剪掉不可能成功的分支，才是回溯的主要过程。
