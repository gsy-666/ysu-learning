# 第01讲：从零理解算法与复杂度

依据：绪论课件第6—13页，教材第2章第2.1、2.2节。教材书页24的脚注规定，没有特别说明的对数以2为底。

本讲先教你数程序执行次数，再用O、Ω、Θ描述增长。代码语法可对照 [SPARKS详解](02-SPARKS语言详解.md)。

## 1. 算法、程序、输入规模

算法是解决一类问题的明确步骤；程序是把步骤写成计算机可以执行的形式。例子：给出[3,7,2,9,4]求最大值，先记住3，再依次比较7、2、9、4，遇到更大的就更新，最后得到9。这个方法还能处理其他非空数列。

这里输入规模n是数的个数，n=5。它不是最大的那个数：把9改为9000，元素个数仍是5。图算法通常用顶点数V、边数E描述规模。

课件要求掌握算法的五个特性：

| 特性 | 从零理解 |
|---|---|
| 确定性 | 每一步含义明确，没有歧义 |
| 能行性 | 每种基本操作原则上能在有限时间完成 |
| 输入 | 可以有0个或多个输入 |
| 输出 | 产生1个或多个结果 |
| 有穷性 | 对合法输入，经过有限步骤后终止 |

有穷不等于足够快。运行很多年但步骤数有限，仍可能满足有穷性；效率需要另外分析。

## 2. 为什么数操作次数

同一程序在不同电脑上的秒数会变化。分析通常约定基本比较、赋值、数组访问和基本算术为常数时间，重点看输入增大时计算量怎样增长。

找最大值时，第一个数初始化，其余n−1个数各比较一次。即使计入循环检查和赋值，总次数通常仍可写成an+b，其中a、b为常数，增长是线性的。

分析步骤：确定n的含义→找关键操作→数重复次数→提取增长阶。代码行数少，不代表执行次数少。

## 3. 增长阶到底是什么意思

例如T(n)=3n²+10n+5。对很大的n，n²项决定增长；乘3、加10n、加5不改变平方增长的阶，所以为Θ(n²)。

| 示范次数函数 | n=8 | n=16 | 增长阶 |
|---|---:|---:|---|
| 100 | 100 | 100 | Θ(1)，常数 |
| log₂n | 3 | 4 | Θ(log n)，对数 |
| n | 8 | 16 | Θ(n)，线性 |
| n log₂n | 24 | 64 | Θ(n log n) |
| n² | 64 | 256 | Θ(n²)，平方 |
| 2ⁿ | 256 | 65536 | Θ(2ⁿ)，指数 |

由慢到快常见顺序是：1、log n、n、n log n、n²、n³、2ⁿ、n!。这是规模足够大时的增长趋势。

Θ(1)表示次数不随n增长，不表示只执行1次。表中常数100在n=8时比n更大，因此低增长阶不保证每个小规模输入上实际用时都更少。

固定不同底数的对数只差常数倍，复杂度可写Θ(log n)。但计算确切次数和整数门槛时，底数必须确定。

## 4. 循环次数：从实际执行开始数

以下work()代表常数时间操作，n为非负整数；涉及log n的次数公式另要求n≥1。repeat是本书相应循环的结束标记。

### 4.1 单层循环

```text
for i ← 1 to n do
    work()
repeat
```

i取1至n，共n次，时间Θ(n)。n=0时循环体0次，但程序仍可能有常数初始化工作；渐近阶描述规模增长时的行为。

### 4.2 两层循环不一定是平方级

```text
for i ← 1 to n do
    for j ← 1 to n do
        work()
    repeat
repeat
```

外层n轮，每轮内层n次，总共n²，时间Θ(n²)。如果内层只从1到3，总共3n次，就是Θ(n)。必须看每轮次数，不能只看循环层数。

### 4.3 三角形循环

```text
for i ← 1 to n do
    for j ← 1 to i do
        work()
    repeat
repeat
```

n=4时，各轮1、2、3、4次，总共10次。一般总数1+2+…+n=n(n+1)/2=(n²+n)/2，时间Θ(n²)。

### 4.4 每次翻倍与“差一次”

```text
i ← 1
while i ≤ n do
    work()
    i ← 2*i
repeat
```

n=16时，实际处理1、2、4、8、16，共5次。32是停止时的值，不进入循环体。

n≥1时次数是floor(log₂n)+1：因为2ᵏ≤n，k从0取到floor(log₂n)，共比最大k多1个整数。时间Θ(log n)。

若从i=n开始，每轮令i←floor(i/2)，在i>1时继续，次数是floor(log₂n)。两种循环同阶，但具体次数可能差1。

### 4.5 顺序执行与过程调用

先做n次，再做n²次，总数n+n²，时间Θ(n²)。顺序代码相加，嵌套代码按真实次数计算。

循环中调用的过程也需要时间。如果外层n次，每次调用一个Θ(n)过程，总时间为Θ(n²)，即使表面只有一层for。

## 5. O、Ω、Θ与最好、最坏的区别

| 记号 | 名称 | 含义 |
|---|---|---|
| O(g(n)) | 渐近上界 | n足够大时，T(n)不超过g(n)的某常数倍 |
| Ω(g(n)) | 渐近下界 | n足够大时，T(n)不低于g(n)的某正常数倍 |
| Θ(g(n)) | 紧确渐近界 | n足够大时，T(n)在g(n)的两个正常数倍之间 |

对最终非负的函数，定义为：

```text
O：存在c>0、n₀，使所有n≥n₀都有T(n)≤c·g(n)。
Ω：存在c>0、n₀，使所有n≥n₀都有T(n)≥c·g(n)。
Θ：存在c₁>0、c₂>0、n₀，使所有n≥n₀都有
   c₁·g(n)≤T(n)≤c₂·g(n)。
```

这些常数不能随n改变。以T(n)=3n+2为例：n≥1时，3n≤3n+2≤5n，所以它属于O(n)、Ω(n)、Θ(n)。

3n+2也属于O(n²)，只是上界宽松。若要表示确定是线性阶，用Θ(n)。不能因为一个O界不紧就直接判错。

最好、平均、最坏先决定分析哪个时间函数，O、Ω、Θ再描述该函数。顺序查找最好时间Θ(1)，最坏时间Θ(n)；不能把Ω解释成最好情况。

考试问时间复杂度，通常给尽量紧的阶并说明次数；明确问上界、下界、紧确界时分别用O、Ω、Θ；判断某个O关系时按定义。

## 6. 空间复杂度

| 额外存储 | 辅助空间 |
|---|---|
| 固定数量变量 | Θ(1) |
| 长度n的新数组 | Θ(n) |
| n×n的新二维表 | Θ(n²) |
| 最深n层、每层固定存储的调用栈 | Θ(n) |

输入数组与额外辅助空间要分清。课件有时计输入在内的总空间，作答应说明口径。时间与空间分别分析。

## 7. 教材习题2.1完整解析：先说取值范围

原题在书页50／PDF第57页，问第二个函数严格小于第一个的最小n。题面该句未明确n是否允许0；以下按整数规模讨论，答案注明约定。

### （1）n²与10n

10n<n²。n=0时相等，不满足；n>0时除以n得10<n，所以最小整数11。n=10相等，不能算进严格小于。

### （2）2ⁿ与2n³

注意是2n³。若允许非负整数，n=0已有0<1，最小值为0。若要求正整数，首次成立在12：n=11时2662>2048，n=12时3456<4096。

若题目问从哪个整数开始，之后所有更大的整数都成立，门槛为12。它与第一次满足条件的最小非负整数是不同问题。

### （3）n²/log₂n与n(log₂n)²

n>1时化简为(log₂n)³<n。n=0对数无定义，n=1分母为0；n=2时1<2，故原题最小有效整数是2。

数值检查可得：整数n=2成立，3至981不成立，982及以后成立。若问最终一直成立的门槛，才答982。

较大门槛通过数值法求：n=512时9³=729>512，n=1024时10³=1000<1024。在这段较大的区间逐次二分，最后比较：

```text
(log₂981)³≈981.547474>981，不成立。
(log₂982)³≈981.983064<982，成立。
```

较大的等式交点约981.970。首轮理解题意和计算方法即可，无须花大量时间手算小数。

### （4）n³/2与n^2.81

n^2.81<n³/2。n=0相等；n>0时化简为n^0.19>2，即n>2^(1/0.19)≈38.403，所以最小整数39。

比较实际数值时要保留原题常数和指数。渐近阶判断趋势，确切门槛计算原不等式。

## 8. 分级练习

以下为自编题；答案在下一节。首轮理解例题，第二轮遮住答案集中做。

1. T(n)=5n²+3n+9的紧确阶？它属于O(n³)吗？
2. n=16，i从1开始，每轮翻倍，在i≤n时执行，共几次？
3. 外层i从1至n，内层j从1至5，共做多少次常数操作？
4. 外层i从1至n，内层j从1至i，n=4时几次？一般阶是什么？
5. 顺序查找第一个就命中与全部查完仍没找到，分别什么阶？
6. 固定5个额外变量，与新开n×n表，辅助空间分别是多少？
7. i从n开始，while i>1，每轮减2，n为非负整数，共几次？

## 9. 标准答案与详细解析

### 第1题

**答案：紧确阶为Θ(n²)；T(n)=O(n³)也成立。**

5n²+3n+9中最高次数为2，常数倍5和低阶项不改变增长阶。O只要求上界，n²最终也不会超过n³的某个常数倍，因此O(n³)正确但不紧。题目若问紧确阶，写Θ(n²)。

### 第2题

**答案：5次；一般次数floor(log₂n)+1，时间Θ(log n)。**

n=16时，实际进入循环体的i依次为1、2、4、8、16。第五次执行后i变成32，再检查32≤16为假，退出。32不能算成第六次执行。

### 第3题

**答案：5n次常数操作，时间Θ(n)。**

外层n轮，每轮内层固定5次，乘起来为n×5。内层不随n增长，因此即使写了两层for，仍是线性阶。

### 第4题

**答案：n=4时10次；一般次数n(n+1)/2，时间Θ(n²)。**

第i轮内层执行i次，所以n=4时为1+2+3+4=10。一般把各轮相加，再把(n²+n)/2中的主导项n²提取出来。

### 第5题

**答案：第一个就命中为Θ(1)；全部查完仍没找到为Θ(n)。**

前者只检查一个元素，后者要检查n个。这里先选定最好、最坏这两种运行情况，再分别描述它们的增长阶，不能将Ω直接等同于最好情况。

### 第6题

**答案：固定5个额外变量为Θ(1)，n×n新表为Θ(n²)。**

5不会随n变化，所以是常数空间；表有n²个格子，若每格固定存储大小，空间随n²增长。本题只问辅助空间，不另把输入数组加进去。

### 第7题

**答案：floor(n/2)次；每轮固定成本时，时间Θ(n)。**

n=2k时，进入循环体的值为2k、2k−2、…、2，共k次；n=2k+1时为2k+1、2k−1、…、3，也为k次。n=0、1都不执行。两种奇偶情况统一为floor(n/2)。
