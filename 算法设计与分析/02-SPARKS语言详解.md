## 1. 先认识一段SPARKS算法

SPARKS是教材采用的算法描述语言，形式接近ALGOL、PASCAL。教材也允许把自然语言和数学表达式加入算法描述，称为“拟SPARKS”。考试写法应保持含义明确、控制结构完整。

先看求最大元素位置的过程，输入n个可比较的数，要求n≥1：

```text
procedure MAX(A,n,j)
    //输入：A的前n个元素，n≥1；输出：最大元素的下标j//
    xmax ← A(1); j ← 1
    for i ← 2 to n do
        if A(i) > xmax then
            xmax ← A(i)
            j ← i
        endif
    repeat
end MAX
```

读算法时，按这个顺序检查：过程要解决什么问题；参数是什么；变量初值是什么；哪些语句重复执行；何时结束；结果通过什么方式交出去。

这里A和n提供输入，j带出结果；xmax保存当前最大值，i用于逐个检查。`end MAX`结束过程并返回调用者。它不表示把xmax自动作为函数值返回。

## 2. 数据类型、变量与赋值

### 2.1 四种基本数据类型

| 类型 | 写法 | 例子及作用 |
|---|---|---|
| 整型 | integer | 下标、元素个数、计数器，如i、n、count |
| 实型 | real | 可带小数的数值，如weight、cost |
| 布尔型 | boolean | 取值为true或false，如found |
| 字符型 | char | 单个字符，如'A' |

声明例子：

```text
integer i,n,count
real weight,cost
boolean found
char grade
```

教材规定标识符以字母开头，不使用特殊符号，不区分大小写，不能与保留字重名。因此教材中的`MAX`和`max`不能被理解成两个不同标识符。笔记中的中文只作解释、注释或占位说明。

### 2.2 赋值箭头与相等号

```text
x ← 5
x ← x+1
```

第一句把5存入x。第二句先读取旧x，计算x+1，再用结果更新x；若原来x=5，执行后x=6。

| 写法 | 意思 |
|---|---|
| x ← y | 把y的值赋给x，会改变x |
| x = y | 判断两者是否相等，产生布尔值 |
| x ≠ y | 判断两者是否不相等 |

同一行可以用分号分隔多条语句：`x ← 1; y ← 2`。执行顺序仍然是先左后右。

### 2.3 顺序赋值不等于同时赋值

假设x=3、y=5，执行：

```text
x ← y
y ← x
```

最后两者都是5，因为第二句使用的是已经更新后的x。交换需要保留旧值：

```text
t ← x
x ← y
y ← t
```

### 2.4 算术、关系与逻辑运算

算术表达式可以使用加减乘除及明确的数学表达式。教材没有在本节完整规定混合算术规则；需要整数商时，本笔记明确写`floor(a/b)`，表示向下取整，避免默认某种编程语言的截断规则。

关系运算符为`<、≤、=、≠、≥、>`。逻辑运算符为`and、or、not`，例如：

```text
(x ≥ 0) and (x ≤ 100)
(x < 0) or (x > 100)
not found
```

复杂条件用括号明确分组。本书明确采用短路求值：`P and Q`在P为假时不计算Q；`P or Q`在P为真时不计算Q。

例如，`(i ≤ n) and (A(i) ≠ x)`会先判断下标是否有效。若i已经超过n，就不会继续读取A(i)。把两个条件颠倒可能先访问越界位置。

## 3. 数组：括号、范围和任意下界

SPARKS用圆括号访问数组元素：`A(i)`相当于常见编程语言中的`A[i]`。同样形状的`F(x)`也可能是函数调用，要根据A或F的定义判断。

```text
integer A(1:n)
integer B(0:n)
integer C(5,7:20)
```

| 声明或写法 | 含义 |
|---|---|
| A(1:n) | 下标1至n，共n个元素 |
| B(0:n) | 下标0至n，共n+1个元素 |
| C(5,7:20) | 二维数组，等价于C(1:5,7:20) |
| C(i,j) | 第一个下标为i、第二个下标为j的元素 |

本书约定：数组某一维下界为1时，可以省略该维的`1:`。因此`C(5,7:20)`的5表示第一维上界，不是第一维下界。它有5×(20−7+1)=70个元素。

一般地，整数下标范围l:u含u−l+1个位置（前提l≤u）。写算法前先看清下标范围，不能把所有数组都自动当成从0开始。

### 3.1 把C(5,7:20)完整拆开

这里讨论的是数组声明，例如`integer C(5,7:20)`。二维数组可以先想成一张有行、有列的表：第一个维度表示行，第二个维度表示列。

```text
integer C(5, 7:20)
          │   │
          │   └─ 第二维：下标从7到20
          └───── 第一维：省略下界1，完整范围是1:5
```

所以它等价于`integer C(1:5,7:20)`：行下标可取1、2、3、4、5；列下标可取7、8、9、…、20。两个范围都包含端点。

| 行下标 / 列下标 | 7 | 8 | 9 | … | 20 |
|---|---|---|---|---|---|
| 1 | C(1,7) | C(1,8) | C(1,9) | … | C(1,20) |
| 2 | C(2,7) | C(2,8) | C(2,9) | … | C(2,20) |
| 3 | C(3,7) | C(3,8) | C(3,9) | … | C(3,20) |
| 4 | C(4,7) | C(4,8) | C(4,9) | … | C(4,20) |
| 5 | C(5,7) | C(5,8) | C(5,9) | … | C(5,20) |

表格里写的是每个格子的访问方式，尚未给出格子中存放的数值。

### 3.2 为什么有14列、70个元素

7至20共有20−7+1=14个整数。减法20−7只得到两个端点的差，加1才把两个端点都算上。就像7、8、9有3个数，而9−7只等于2。

第一维有5−1+1=5行，每行14个元素，所以总数为5×14=70。这是5行14列的数组；列的最后编号20不等于列的数量。

### 3.3 数组声明与访问某个元素

声明`integer C(5,7:20)`是在规定整张表的范围。使用`C(3,10)`则访问其中一个格子：第一维下标为3，第二维下标为10。

列编号从7开始，所以列下标10对应从左数第10−7+1=4列。可以叫它“列标10”，避免把它误认为从左数第10列。

```text
C(3,10) ← 42
```

这句将42存入行标3、列标10的格子。3和10是位置编号，42是内容；赋值不会改变整个数组的行列范围。

| 访问 | 是否合法 | 原因 |
|---|---|---|
| C(1,7) | 合法 | 两个下标都在范围内，是左上角 |
| C(5,20) | 合法 | 两个下标都在范围内，是右下角 |
| C(3,10) | 合法 | 1≤3≤5，7≤10≤20 |
| C(0,10) | 越界 | 第一维不能取0 |
| C(6,10) | 越界 | 第一维超过5 |
| C(3,6) | 越界 | 第二维小于7 |
| C(3,21) | 越界 | 第二维超过20 |

### 3.4 怎样遍历整张表

如果要把所有元素设为0，两个循环分别使用各自的真实下标范围：

```text
for i ← 1 to 5 do
    for j ← 7 to 20 do
        C(i,j) ← 0
    repeat
repeat
```

外层5轮，每轮内层14次，共70次赋值。第二维的循环不能从1开始，否则会访问不存在的列标1至6。

### 3.5 两道检查题与答案

1. `integer D(3,4:8)`的下标范围和元素个数是什么？
2. `integer E(0:2,-1:1)`有多少元素？E(0,0)是否合法？

答案：第1题等价于D(1:3,4:8)，共3行、5列、15个元素。第2题两维分别为0、1、2和−1、0、1，共3×3=9个元素，E(0,0)合法。本书允许任意整数下界，因此是否允许下标0或负数，要看实际声明。

## 4. 选择结构：if与case

### 4.1 条件成立才执行

```text
if x < 0 then
    x ← -x
endif
```

条件真，执行then部分；条件假，跳过。`endif`标记这条条件语句结束。

### 4.2 两种情况二选一

```text
if a ≥ b then
    large ← a
else
    large ← b
endif
```

then与else只执行其中一边。这里large得到较大的值。

### 4.3 嵌套if

```text
if a > b then
    if a > c then
        large ← a
    else
        large ← c
    endif
else
    if b > c then
        large ← b
    else
        large ← c
    endif
endif
```

每条if都要对应自己的endif。通过缩进看所属层次，不能只按“离哪个then近”猜测else的归属。

### 4.4 多分支case

本书case的写法是依次测试条件；找到第一条成立的条件，执行对应语句组，随后离开case。

```text
case
    : score ≥ 90 : grade ← 'A'
    : score ≥ 60 : grade ← 'B'
    : else : grade ← 'C'
endcase
```

假定score在0至100之间。score=95时，第一条已成立，grade为'A'；即使第二条条件也成立，也不会再改成'B'。条件排列顺序会影响结果。else是可选的兜底分支。

## 5. 循环结构：读清条件、更新和结束标记

### 5.1 while：先判断，真则继续

```text
while cond do
    S
repeat
```

cond是条件，S代表循环体。每轮先检查cond；为真才执行S，再返回检查；为假则退出。第一次条件就为假时，循环体执行0次。

求1至n的和，假设n为非负整数：

```text
s ← 0; i ← 1
while i ≤ n do
    s ← s+i
    i ← i+1
repeat
```

n=3时，循环体执行3次，s依次为1、3、6；i变成4后条件为假，结束。n=0时，循环体执行0次，s仍为0。

检查while时必须找变量更新。若删掉`i ← i+1`，n≥1时条件就可能一直为真，形成无限循环。

### 5.2 for：给定起点、终点和步长

完整形式为：

```text
for v ← start to finish by increment do
    S
repeat
```

省略`by increment`时默认步长为+1。正步长时，只要v≤finish就执行；负步长时，只要v≥finish就执行。步长应非零，循环体不修改控制变量v。

```text
for i ← 1 to 4 do
    print(i)
repeat
```

依次输出1、2、3、4。

```text
for i ← 5 to 1 by -2 do
    print(i)
repeat
```

依次输出5、3、1。随后i变成−1，不再执行循环体。

```text
for i ← 1 to 6 by 2 do
    print(i)
repeat
```

只输出1、3、5。终点是允许到达的边界，不保证每次都刚好取到终点。

对整数循环，正步长d>0且start≤finish时，循环次数为floor((finish−start)/d)+1；若起点已经超过终点，则为0次。负步长可按相应方向计算。

本书还说明：start、finish、increment在进入for时计算并保存一次。因此循环体改变原来的终点表达式所用变量，不会重新设置已经保存的终点。为避免混淆，考试算法通常保持边界变量不变。

### 5.3 loop—until—repeat：先执行，真则结束

```text
loop
    S
until cond repeat
```

先执行S，再判断cond；cond为真则结束，为假则继续。因此循环体至少执行1次。

```text
i ← 0
loop
    i ← i+1
until i ≥ 3 repeat
```

i依次变成1、2、3，共执行3次，在i≥3第一次成立时结束。

| 结构 | 判断时机 | 条件为真时 | 最少执行次数 |
|---|---|---|---|
| while cond do … repeat | 循环体之前 | 继续执行 | 0 |
| loop … until cond repeat | 循环体之后 | 结束循环 | 1 |

若把while改写成先执行的循环，需要额外检查“本来应该执行0次”的情况，不能只把关键词互换。

### 5.4 loop—repeat与exit

```text
loop
    S
repeat
```

该结构本身没有结束条件。教材可以在循环体里使用exit退出，例如：

```text
i ← 0
loop
    i ← i+1
    if i = 3 then exit endif
    print(i)
repeat
```

输出1、2。i变成3时立即退出，后面的print不执行。

exit退出包含它的最内层循环，随后执行那个循环后面的语句。它与return的作用范围不同：return离开当前过程。

### 5.5 repeat到底是什么意思

在本书中，不能仅看到repeat就判断“至少执行一次”。必须和起始关键词配对：

- `while … repeat`：由while条件控制，可能执行0次。
- `for … repeat`：由起点、终点、步长控制，可能执行0次。
- `loop … until … repeat`：先执行再判断，至少1次。
- `loop … repeat`：没有自带终止条件，要看exit、return等出口。

教材还介绍了`go to label`：跳转到某条带标号的语句。一般先用结构化的if、循环和exit表达；读到go to时，沿标号继续追踪控制流即可。

### 5.6 嵌套循环的配对

```text
for i ← 1 to n do
    for j ← 1 to i do
        print(i,j)
    repeat
repeat
```

第一个repeat结束内层for，第二个repeat结束外层for。n=3时输出(1,1)、(2,1)、(2,2)、(3,1)、(3,2)、(3,3)，共6对。

一般执行次数为1+2+…+n=n(n+1)/2。按每次print为常数时间的模型，时间复杂度为Θ(n²)。

## 6. 过程、函数、参数和结果

### 6.1 过程的外壳

```text
procedure NAME(参数表)
    说明部分
    语句序列
end NAME
```

说明部分可以写变量类型及作用域。教材介绍local（局部变量）、global（全程变量）和parameters（形式参数）。

| 名称 | 含义 |
|---|---|
| 局部变量 | 在当前过程中使用的临时变量，例如循环下标i |
| 全程变量 | 由包含当前过程的外层过程声明，可能被多个相关过程使用 |
| 形式参数 | 过程定义中的参数名，如MAX(A,n,j)里的j |
| 实际参数 | 调用时提供的具体数组、变量或表达式，如call MAX(B,m,pos)里的pos |

MAX(B,m,pos)中，B对应A，m对应n，pos对应j。按本书的参数规则，过程可以通过修改输出形参，把结果带到对应实参中。实际读算法时，必须分清参数是只提供输入，还是会被过程更新。

教材允许省略含义明显的声明，未作特别说明的变量视为局部变量或形参。完整说明的一种示例如下，其中把xmax明确设为局部变量：

```text
procedure MAX(A,n,j)
    parameters integer n,j; real A(1:n)
    local integer i
    local real xmax
    //这里接MAX的算法主体，要求n≥1//
end MAX
```

上面只展示声明位置，注释处需要替换成真正的主体。教材还用把xmax设为global的版本解释全程变量；所以阅读原书时，要以该段具体声明为准。

### 6.2 纯过程：用参数带出结果

```text
call MAX(A,n,pos)
print(pos,A(pos))
```

执行MAX后，pos获得最大元素的位置；第二句输出这个位置和对应数值。MAX没有使用return(最大值)，所以不能默认写`answer ← MAX(A,n,pos)`来获得最大值。

从数据流看，参数常分为in、out、inout三类：in只带入；out由过程计算后带出；inout既带入旧值，也带出更新值。这是解释参数作用的分类，不要求在所有SPARKS算法中都写成声明关键词。

### 6.3 函数过程：用return(表达式)返回值

本书的函数过程也用procedure开头，但通过`return(表达式)`给出函数值。例如求和，n为非负整数：

```text
procedure SUM(A,n)
    //输入：A的前n个元素；返回：这n个元素的和//
    integer i
    real s
    s ← 0
    for i ← 1 to n do
        s ← s+A(i)
    repeat
    return(s)
end SUM
```

调用时可以写：

```text
total ← SUM(A,n)
```

return(s)立即结束本次调用，把s的值交给调用者。SUM中n=0时不访问数组，返回0。非空时逐项相加，时间为Θ(n)，辅助空间为Θ(1)。

### 6.4 四种结束方式不要混淆

| 写法 | 控制流去哪里 |
|---|---|
| exit | 离开最内层循环，继续当前过程 |
| return或return(值) | 离开当前过程，回到调用者；有括号值时交回函数值 |
| end NAME | 当前过程自然结束，回到调用者；主过程结束则结束其执行 |
| stop | 停止整个程序的执行 |

纯过程可以提前return而不带函数值。函数过程需要在对应返回路径上给出所需的值。教材允许过程直接或间接调用自身，递归的出口和调用栈在下一阶段学习。

### 6.5 输入、输出与注释

```text
read(n)
print(n)
//这是一条注释//
```

read把输入值读入参数，print输出参数。本书没有规定复杂的输入输出格式。注释使用首尾双斜线，帮助说明输入、输出、前提和关键步骤，注释本身不参与执行。

## 7. 完整例题一：MAX逐轮执行

仍使用本讲开头的MAX，输入A=[5,2,8,8]、n=4。

| 阶段 | 本轮A(i) | A(i)>xmax是否成立 | 处理后的xmax | 处理后的j |
|---|---:|---|---:|---:|
| 初始化 | — | — | 5 | 1 |
| i=2 | 2 | 否 | 5 | 1 |
| i=3 | 8 | 是 | 8 | 3 |
| i=4 | 8 | 否，相等不满足严格大于 | 8 | 3 |

最后j=3，最大值为A(3)=8。严格大于号使并列最大值保留第一次出现的位置；若改为≥，则每次遇到相等值也更新，最后j=4。

为什么不能把xmax初始化为0？如果A=[−5,−2,−8]，0并不是数组元素，并且所有元素都小于0，结果就会错误。用A(1)初始化既适用于正数，也适用于负数，但要求n≥1。

课件第15页注释写了n≥0，而主体访问A(1)。应把这一版本的前提改为n≥1；教材书页32的原例写的是n>0。若允许空数组，必须另外规定“没有最大元素”时怎么处理。

核心比较执行n−1次，因此时间为Θ(n)。只额外使用xmax、i、j等固定数量的变量，辅助空间为Θ(1)。

## 8. 完整例题二：查找元素，理解短路与返回

下面返回x第一次出现的下标，找不到则返回0。数组有效元素下标为1至n，n为非负整数；n=0表示没有有效元素。

```text
procedure FIND(A,n,x)
    integer i
    i ← 1
    while (i ≤ n) and (A(i) ≠ x) do
        i ← i+1
    repeat
    if i ≤ n then
        return(i)
    else
        return(0)
    endif
end FIND
```

输入A=[4,8,8,2]、x=8时：i=1的元素不相等，于是i加到2；随后A(2)=8，while条件为假，跳出循环，返回2。

输入x=9时：检查完A(4)，i变成5。此时i≤n为假，短路规则使A(5)不会被访问，最后返回0。n=0时同样先被边界条件拦住，返回0。

最好情况在第一个位置找到，时间为Θ(1)；最坏情况检查全部元素，时间为Θ(n)。辅助空间为Θ(1)。

## 9. 用SPARKS读教材习题2.3左侧循环

教材书页50／PDF第57页的左侧程序片段是：

```text
i ← n
while i > 1 do
    y ← F(x)
    i ← i-2
repeat
```

假设n为非负整数。n=5时，进入循环体的i为5、3，随后变成1并停止；n=4时，进入循环体的i为4、2，随后变成0并停止。

可以用更直接表达递减计数的for改写：

```text
for i ← n to 2 by -2 do
    y ← F(x)
repeat
```

终点写2，表示只要i≥2就执行；它不会保证每条下降序列都刚好经过2。这两个片段都调用F(x)共floor(n/2)次。若F每次调用是常数时间，则整体为Θ(n)；若F的成本未知，就不能只数外层循环而忽略它。

习题2.3右侧还有嵌套条件。读这类题时，先给每条if、else、endif配对，再考虑改写成case，避免把分支归属看错。

## 10. 考试写算法的顺序与易错点

写解法时，先说明输入、输出和取值范围；初始化变量；写循环或递归的推进步骤；确认能停止；最后说明结果和复杂度。若题干指定SPARKS，就优先沿用本书的语法格式。

| 常见问题 | 应检查什么 |
|---|---|
| 把←写成= | 当前是在赋值，还是判断相等？ |
| 误认为repeat一律至少执行一次 | 它对应while、for，还是loop-until？ |
| while条件写反 | 真时继续，还是假时继续？ |
| until条件写反 | 它为真时应结束 |
| for漏写负步长 | 默认是+1，倒序必须明确by -1等 |
| 循环次数差1 | 首尾是否都包含？停止时的值有没有进入循环体？ |
| if或循环层次不清 | endif、repeat分别与哪个起点配对？ |
| 把xmax设为0 | 输入是否可能全是负数？ |
| n=0仍访问A(1) | 是否规定非空前提，或单独处理空输入？ |
| 最后一个并列最大值意外覆盖第一个 | 判断使用的是>还是≥？ |
| 过程算出了结果但调用者拿不到 | 结果通过输出参数还是return(值)传出？ |
| 复杂度只看循环层数 | 各轮实际执行几次，内部调用成本是多少？ |

## 12. 标准答案与详细解析

### 第1题：顺序赋值与交换

**答案：原两句执行后x=5、y=5。正确交换后应为x=5、y=3。**

原程序先执行x←y，把x从3改成5；第二句y←x读到的是已经变成5的x，所以y仍为5，旧的3已经丢失。交换需先保存旧x：

```text
t ← x       //t=3，先保留旧x//
x ← y       //x=5//
y ← t       //y=3//
```

### 第2题：负步长for

**答案：依次输出6、4、2，共3次。**

步长−2时，只要i≥终点1就执行。i=6、4、2均满足；再减2得到0，0≥1为假，退出。终点是边界，并不要求数列恰好取到1。

### 第3题：先判断与后判断

**答案：while执行0次，结束时i=3；loop-until执行1次，结束时i=4。**

while第一步判断3<3为假，根本不进循环体。loop先执行i←i+1得到4，再判断4≥3为真，于是结束。这就是至少执行一次与可能执行零次的区别。

### 第4题：并列最大值的位置

**答案：使用>时j=3；使用≥时j=4。最大元素的值两者均为8。**

读到第3个元素8时，最大值从5更新为8，位置改为3。第4个也是8：严格大于条件8>8为假，所以不改；大于等于条件8≥8为真，所以位置再次改为4。

### 第5题：查找与短路求值

**答案：查找8返回2；查找9返回0；两种情况都不会访问A(5)。**

查8时，i=1处的4不等于8，i加到2；A(2)=8使while条件为假，返回2。虽然第3个也是8，本算法停在第一个命中位置。

查9时，4个元素都不匹配，i加到5；此时(i≤n)为假，and短路，不再计算A(i)≠9。退出后i≤n仍为假，走return(0)。因此先做边界判断很重要。

### 第6题：统计正数的完整算法

**答案：返回严格大于0的元素个数。样例[−2,0,3,5]返回2，空输入返回0；时间Θ(n)，辅助空间Θ(1)。代码如下。**

```text
procedure COUNT_POS(A,n)
    //输入：前n个有效元素，n≥0；返回：正数个数//
    integer i,count
    count ← 0
    for i ← 1 to n do
        if A(i) > 0 then
            count ← count+1
        endif
    repeat
    return(count)
end COUNT_POS
```

例如A=[−2,0,3,5]、n=4时返回2；n=0时循环不执行，返回0。逐个检查一次，时间为Θ(n)，辅助空间为Θ(1)。这里的Θ(n)描述输入规模增长的情形；空输入本身只需要常数工作。

逐项核对：−2不计，0也不满足严格大于0；3使count从0变1，5使count从1变2。初始化count=0与最后return(count)都不可漏。

学完本讲，应能解释←和=、数组下界、短路求值、while与until、for步长、repeat配对、exit与return，以及输出参数与函数值。之后进入递归时，继续使用这套书写规则。
