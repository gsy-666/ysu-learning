# 已核对的课件勘误与限定条件

这些内容留到对应章节使用。前三处公式或代码已查看原PDF图片确认，不是单纯的文字提取问题。最后补充了MAX的输入前提，与教材原例对照使用。

## 1. Strassen矩阵乘法

《3、分治法.pdf》第32页定义P₇=(A₁₁−A₂₁)(B₁₁+B₁₂)。按这一套定义，右下子矩阵应为：

```text
C₂₂ = P₅ + P₁ − P₃ − P₇
```

课件末项写成了+P₇。例如令A、B都为2阶单位矩阵，课件的加号公式会算出C₂₂=3，正确结果为1。其他版本可能把P₇本身定义成相反数，需整套核对，不能只比较一处符号。

## 2. 矩阵连乘的分割点

《5、动态规划.pdf》第21页，计算区间[i,j]时，分割点范围应为：

```text
for k ← i to j−1 do
```

原图从1开始，会包含区间外的分割点。正确转移为m[i,j]=min(m[i,k]+m[k+1,j]+p[i−1]·p[k]·p[j])，其中i≤k<j。

## 3. LCS的边界

《5、动态规划.pdf》第24页，零边界应为i=0或j=0，原图仅写了i=j=0。任意一个序列前缀为空，最长公共子序列长度都为0。

## 4. MAX求最大元素的输入前提

《1、绪论.pdf》第15页MAX注释写n≥0，主体却立即访问A(1)。这一版本应要求n≥1；教材第2.3节书页32／PDF第39页的原例明确写n>0。若允许n=0，需要先规定空输入的结果并单独处理。

## 分析时补充说明

- 快排：常见划分版本平均Θ(n log n)，最坏Θ(n²)。看到课件只写O(n log n)时，要补上情况限定。
- 贪心背包：输入已经按价值密度排好序时，选取过程为O(n)；计入通常的比较排序，整体为O(n log n)。
- 二分检索：迭代版辅助空间Θ(1)；递归版通常有Θ(log n)调用栈。课件含输入数组的总空间与辅助空间不是同一口径。
- 递归不必然低效。朴素Fibonacci的主要问题是重复求解大量相同子问题。
- Dijkstra要求边权非负；最小生成树算法允许负权边。
