# 算法考试复习路线：零基础学懂，再练到能独立答题

这份资料按你的要求调整：概念从头解释，算法讲清为什么这样做，代码逐步执行，例题完整演算，再给练习和解析。目标是让你能读题、选方法、写过程、写算法和分析复杂度。

做完练习后可直接打开 [各章练习答案速查](10-各章练习答案速查.md) 核对结果，再回对应章节查看逐题的标准答案与详细解析。递归的调用树、算法题的完整代码、过程题的表格与搜索树均在同题解析中。

当前材料为五份课件、教材《计算机算法基础（第三版）》，以及你确认也考的回溯法。绪论课件第3页列出选择、简答、过程、算法四类题。下面按这些题型组织，不把目录以外内容自动当成考试范围。

## 2. 怎样同时做到讲得清楚和推进得快

第一轮连续过知识：看主文和完整例题，亲手跟踪关键变量；不在每个小点后停下来考试，也不用先刷完整章课后题。代码先看懂变量的含义，再看步骤，不整段机械背诵。

第二轮集中刷题：完成各章末的分级练习，遮住答案独立做，再选本路线列出的教材题。不会时定位具体缺口，回查对应小节。

第三轮做混合题：完成09，训练看题选方法、表达过程和分配时间。整理错题时记录具体原因，隔一段时间关答案重做。

不再把两天当作必须翻完所有页的限制。每天能学几小时，就分成两段集中学习，中间休息；用“能否独立重现例题”决定是否进入下一章。已经会的部分可跳过，卡住的基础先补齐。

## 3. 每章的学习检查点

| 章 | 至少能独立说明 |
|---|---|
| 基础 | 为什么翻倍循环是对数级，为什么嵌套两层不一定是平方级 |
| SPARKS | while/until何时退出，repeat与谁配对，结果通过哪个参数或return带出 |
| 递归 | 调用与返回的先后顺序，每层保存什么，数值递推与耗时递推的区别 |
| 分治 | 二分为什么能删一半，归并怎样合并，快排怎样划分，选择怎样更新排名 |
| 贪心 | 选取依据是什么，能否分割，MST与最短路有何不同，负权影响谁 |
| DP | 每个状态的一句话定义，边界、转移、填表顺序、方案恢复 |
| 回溯 | 当前层选什么，怎样证明剪枝安全，递归后需要撤销哪些共享状态 |

第一次跟着解析会做，只说明你看懂了这一次；合上解析能重做、换组数据也能走通，才更接近独立考试的要求。

## 6. 考前最后检查

先检查理解与书写：输入范围有没有写，边界是否正确，状态定义能否用一句话解释，中间过程有没有漏，输出是值、位置还是方案。

再检查易混点：O/Ω/Θ与最好最坏；递归与分治；可分割与0/1背包；Prim与Dijkstra；最长公共子序列与子串；回溯的局部返回与全局停止。

最后检查复杂度口径：是否计入排序、被调用过程、递归栈、输入存储和结果输出；题目指定教材算法时是否沿用同一版本。
